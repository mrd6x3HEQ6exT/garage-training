# Rack & Roll coaching standard

The user approved this on 2026-10-19. `audit.js` checks every build against it. Rules marked
**RULE** fail the audit; weekly targets are **WARN** only (user's choice). Change this file only
with the user's agreement, and update `audit.js` (`TARGETS`, `RATIOS`) and the app's
`MUST_HAVES` to match.

## 1. The week (user's settings at approval)
- Goal: Reduce bodyweight (circuits, higher reps, short rest).
- Strength days, 45 min: Mon Push, Tue Pull, Thu Lower, Fri Lower. 7 exercises: 6 for the day's
  muscles + 1 core (core is ON strength days, added as an extra exercise).
- AM cardio Mon–Sat (bike / ski / sled).
- Injury settings: the knee flag covers split squats and lunges only; normal squats are not flagged.

## 3. Balance — WARN
- Push:pull 0.8–1.2.
- Quads:hamstrings 1.0 (warn outside 0.8–1.2).

## 4. Every day must have — RULE
- **Push:** chest press, overhead press, a 2nd chest exercise (fly or similar), triceps, side/rear delt, core.
- **Pull:** vertical pull, a row (max 2), biceps, rear-delt/upper-back, core.
- **Lower:** squat, hamstring hinge, 2 quad exercises, calves, core.
- **Core day** (if planned): at least 3 different kinds of core work.

## 5. Never — RULE
- Banned exercises; hinges on Pull days.
- More than 2 of one job: rows, triceps (incl. close-grip bench), rear-delt/upper-back, glute
  isolation, barbell/Smith presses. More than 1 bench-press variant. More than 3 pressing lifts,
  or 3 pressing lifts in a row.
- Two compound lifts in one circuit; an exercise before the compound that uses its main muscle.
- Drop sets on bodyweight/timed holds; planned reps outside the scheme.
- A repeat from the last session of the same type, unless it is a (+) pick, pinned, or nothing
  else fits.

## 6. Order and pairing — RULE
- Big lifts first, as straight sets.
- Circuits never pair two exercises on the same main muscle (core with core allowed on Core days).
- Core is never last — but never by moving a big lift behind smaller exercises.

## 7. Reps and rest (Reduce bodyweight goal)
- Big lifts 6–10 reps, 1:00 rest. Accessories 3 × 15–20, 0:45. Isolations 3 × 10–12, 0:40.
  Core 3 × 12–20, 0:35.

## 8. Progression
- Clear the top of the rep range on every set: add 5 lb next time (10 lb on barbell lower-body).

## 9. Preferences
- (+) picks: weighted decline sit-up, landmine rotation, barbell calf raise, dragon flag, weighted
  cable crunch, barbell bench press, cable glute kickback, high-to-low woodchop, decline bench
  press, seated barbell press, half-kneeling Pallof press, decline Russian twist.
  Barbell hip thrust is no longer (+) (user, 2026-10-19).
